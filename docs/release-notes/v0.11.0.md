## Upgrading

### Agent state from another pane

A pane sets the agent state only of its own window. A report about another pane needs the `respond` grant. This covers `set-agent-state`, `set-agent-meta`, `set-agent-session`, `report-agent-activity`, `ask-human` and `request-approval`. A hook or another program that tuios starts outside every pane reports for no pane. You can still set the state of any pane from your own terminal outside tuios.

A command under `[hooks]` in your config that calls `set-agent-state` is now refused. tuios runs that command outside every pane.

### A pane that asks the person shows needs_input

While `ask-human` from inside a pane waits, that pane shows `needs_input` with the question as its note. When the call returns, the pane shows its earlier state again. A script that waits for `needs_input` now also wakes on such a question. To tell the two apart, read `list-attention`: the question is an item of kind `ask`.
